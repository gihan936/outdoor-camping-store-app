## Outdoor Camping Store App

This is a Flutter mobile application for an eCommerce store selling outdoor camping equipment. The app allows users to browse a range of camping products, add them to their cart, and proceed to checkout with a summary of their order.

## Features

- **Home Screen**: Displays featured products and promotional banners.
- **Product List Screen**: Shows a grid of camping products with details like name, price, and images.
- **Product Detail Screen**: Provides detailed information about a selected product, with the ability to add products to the cart and update quantities.
- **Cart Screen**: Allows users to manage cart items, update quantities, remove items, and view the total cost, including tax and delivery fees.
- **Checkout Screen**: Displays the total order amount and allows users to complete the purchase.

## Technologies Used

- **Flutter**: The mobile development framework used to build the app.
- **Provider**: Used for state management to handle cart functionality.
- **Dart**: The programming language used for building the app.
